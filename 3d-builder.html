Start here — two different links
  1. Your Firebase .glb is only the 3D model file. It is not an MML “document.” Pasting it in the box below will stay blank.
  2. An MML document is a normal .html page whose job is to point at that GLB (for example with <m-character src="…glb…">).
  3. Per-otter from metadata: use Build MML from metadata below (NFT #). That hits /api/mml?id=…, reads the same metadata/<#>.json as the 3D builder, and points wearables at WEARABLES/Furs|Hats|Shirts|Eyes/… — host those files on Firebase with the same paths (see api/mml.js env vars) or under /AvatarBuilder/ on this site.
  4. Or click Try sample Otter document, then Load in viewer, or paste your mml/MMLOtter-preview.html URL — not a raw .glb.

The red “eval / CSP” line in Chrome Issues often comes from extensions or from code inside viewer.mml.io; it is usually not why the scene is empty. An empty scene here almost always means the wrong kind of URL (a model link instead of an .html document).

Open this tab with #mml in the URL, or add ?url= with your MML document link to jump here pre-filled.
Build from collection metadata
